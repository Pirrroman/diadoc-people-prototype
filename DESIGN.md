# Визуальная система

Режим: Operate. Сотрудник работает со списком документов, получатель — с одним документом на телефоне. Приоритеты: читаемость, понятные статусы, явное следующее действие.

Направление: спокойный кабинет документооборота. Белая рабочая поверхность, светло-серый фон, насыщенный синий для действий. Зелёный — завершение, янтарный — ожидание, красный — отказ. Статусы различаются текстом, не только цветом. Никаких рекламных экранов перед рабочей задачей.

Первый экран: постоянная навигация слева; название раздела и создание документа; компактные счётчики; поиск и список с получателями и статусами. На телефоне строки становятся компактными блоками, навигация переходит наверх.

Получатель: минимум навигации, отправитель, последовательность «Вход — Документ — Готово», одна основная кнопка на этапе. Демоусловия видны, но не смешаны с технической документацией.

Состояния: ошибки рядом с формой, подтверждение разрушительных действий в диалоге, клавиатурный фокус, отзывчивые кнопки, отдельные пустые и недоступные состояния. Единственный заметный анимированный момент — завершение подписания; prefers-reduced-motion соблюдается.
