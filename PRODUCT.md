# Документы клиентам

Статический интерактивный прототип по плану от 02.10.2026. Цель: проверить путь сотрудника компании и клиента-физлица. Первая сцена — автосервис; данные вымышлены.

Пользователь выбрал GitHub Pages и поручил опубликовать прототип в своём аккаунте GitHub. Репозиторий: Pirrroman/diadoc-people-prototype; источник сайта: ветка main, папка /docs.

Объём: один PDF, один получатель, создание черновика, приглашение, два тестовых подтверждения, подписание/отказ/отзыв, история, аналитика и локальное сохранение. Реальная подпись и СМС не реализованы.

Архитектура: HTML/CSS/JavaScript ES Modules, IndexedDB. Нет серверного кода, npm-зависимостей, CDN или вызовов модели из приложения. Упрощение исходной серверной архитектуры необходимо для самостоятельного размещения на GitHub Pages. Репозиторий содержит готовые статические файлы в docs/.

На GitHub Pages файл доступен по HTTPS. Документы сохраняются локально в браузере; передача между устройствами отсутствует. Переключение организаций — демонстрация, не аутентификация. Квитанции не имеют юридической силы.

Следующий этап: сохранить интерфейсы и заменить локальное хранилище серверным API, добавить проверку полномочий, отдельные авторизацию и СМС, согласованную процедуру подписи. Серверную защиту нельзя заменить проверками в браузере.
