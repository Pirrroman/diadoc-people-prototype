# Работа над прототипом

- Читать PRODUCT.md, DESIGN.md и README.md перед изменениями.
- Сохранять совместимость с GitHub Pages: папка docs/ содержит готовые статические файлы; относительные пути и маршруты после #.
- Не добавлять n8n, серверные обработчики, секреты или внешние CDN без изменения архитектуры по запросу пользователя.
- Не выдавать клиентские проверки, локальное хранение и тестовые коды за защиту настоящего сервиса.
- Тестовые данные вымышлены, юридическая подпись не создаётся. Эти ограничения должны оставаться видимыми.
- Проверки: npm test; npm run check. Для важных изменений интерфейса пройти сценарий на настольном и мобильном размерах.
- Все подписи интерфейса и документация для пользователя — по-русски.
- Не публиковать и не отправлять сообщения клиентам без соответствующего запроса.
